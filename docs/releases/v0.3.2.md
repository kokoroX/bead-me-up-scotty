# Scotty v0.3.2 — Upgrade fixes and command palette improvements

This release fixes a regression that v0.3.1 introduced for some users, makes the new security checks easier to work with, and includes four community contributions.

## Fixes

- **Closing beads you claimed before upgrading works again.** v0.3.1 changed the default human actor from your OS username to your git `user.name`, matching `bd` (#61). If those two names differ, beads you had assigned to yourself in Scotty before upgrading still carry the OS username, and `bd` refused to close them: "assignee is X, actor is Y". Closing or archiving a bead assigned to the local OS username now acts as that name, since it is you on this machine. Beads claimed by anyone else, such as a teammate or an agent, keep `bd`'s protection.
- **Refused requests say how to allow them.** v0.3.1 began refusing browser requests that arrive under an unrecognized hostname, and writes sent from other websites. Every refusal now names the exact setting that would allow it, for example `SCOTTY_ALLOWED_HOSTS=tracker.example.com`. Each distinct refusal is also printed once in the terminal running Scotty. `SCOTTY_ALLOWED_HOSTS=*` accepts any hostname and is now documented. It relaxes the hostname check only, so writes from other websites stay refused. See "Opening Scotty by a hostname" in the README.

## Improvements from the community

- **The Board search box is clickable again** in crowded headers: it widens while you type and stays usable at every window width. Fixes #80. (#81, @sryan-pub)
- **Needs You cards show the full description**, rendered as Markdown, instead of a three-line plain-text excerpt. (#67, @aspiers)
- **The command palette shows keyboard shortcuts** next to each command. (#69, @aspiers)
- **The palette's "Go to" lists every view**, including Insights, Activity, Needs You and, when enabled, Achievements. The sidebar and palette now share one list. (#71, @aspiers)

Thank you @sryan-pub and @aspiers!

## Install this release

**Homebrew** (macOS or Linux):

```sh
brew install brendan-appstart/tap/bead-me-up-scotty   # new install
brew upgrade bead-me-up-scotty                        # existing install
```

**From source:** prerequisites are a supported Node.js version (Node 20.9+; Node 22 or newer recommended), npm, and the Beads `bd` CLI for live project data. Without `bd`, Scotty runs with demo data.

```sh
git clone --branch v0.3.2 https://github.com/brendan-appstart/bead-me-up-scotty.git
cd bead-me-up-scotty
npm ci
npm run build
npm run serve
```

Open `http://localhost:3000`. A detached checkout of the release tag is expected and is supported by the stable updater.

## Update an existing installation

**Homebrew:** run `brew upgrade bead-me-up-scotty`, then restart `scotty`. Use Homebrew rather than the in-app "Update now" button.

**Existing Git checkout:** use the in-app update notice, or, after committing or stashing local source changes, run from the app's checkout:

```sh
git fetch origin tag v0.3.2
git merge --ff-only 'v0.3.2^{commit}'
npm ci
npm run build
```

Restart Scotty.

**Global copy, source download or Docker:** build a fresh checkout of this release, then reinstall the global copy, replace the source installation, or rebuild the image. Restart Scotty or recreate the container.

Updating changes Scotty's source and dependencies, not your Beads issue database.

## Scope and validation

This is a source release, installed through Homebrew, Git/source or Docker. It does not publish an npm package. Beads data stays local and is not modified by the release process.

Validation ran the combined tree (the fixes plus the four merged pull requests) on isolated editable and read-only servers, using intercepted browser fixtures and disposable `bd` repositories. All 33 regression scripts pass in their intended server mode. That includes the new `test-close-actor`, which reproduces the v0.3.1 regression against real `bd` 1.3.1 and passes with the fix, and the extended `test-request-guard`. `test-review-links` still contains a selector that fails intermittently when the Needs You badge shows a count. #68 fixes it, and the test passes with the corrected selector. The production build and TypeScript checks pass. Lint reports no errors and the one existing navigation warning. The Homebrew formula installs from source and passes `brew audit --strict` and `brew test`.
